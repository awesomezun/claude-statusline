Ultra has no 5-hour limit, so the weekly line takes its place with a per-day budget.

Why this one

⚡ Effort & thinking

Surfaces /effort (high · xhigh · max) and extended thinking — live, from Claude Code's official JSON.

📊 Every plan, every window

Pro and Max get 5-hour + weekly bars; Ultra (weekly only) gets a weekly bar with a per-day budget. Each limit is read on its own.

🖥️ Truly cross-platform

Bash on macOS and Linux, a native PowerShell renderer on Windows — no Git Bash or jq needed there.

📐 5 sizes × 3 styles

Pick how much you see with one word — xs to xl — then add -plain (no emoji) or -simple (text only) if you like.
